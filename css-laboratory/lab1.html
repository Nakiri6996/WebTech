My First CSS Page

CSS (Cascading Style Sheets) is a style sheet language used for describing the presentation of a document written in HTML or XML. CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.

Without CSS, web pages would be simple and boring. CSS allows you to apply styles to web pages. More importantly, CSS enables you to do this independent of the HTML that makes up each web page.

Reflection

What is the difference between inline, internal, and external CSS?

  • Inline CSS is placed inside the HTML element using the style attribute, internal CSS is placed inside a style element in the HTML document's head section, and lastly external CSS is stored in a separate .css file and linked to an HTML document.

Which method would you use for a website with multiple pages?

  • I would choose external CSS for a website with multiple pages because it lets you update the design across every page from a single file while allowing browsers to cache the stylesheet for faster page loads.
